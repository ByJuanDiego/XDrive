# Tests

Este directorio identifica las pruebas adicionales del proyecto XDrive.

- `upload/tests.py`: contiene las pruebas principales de carga, fragmentación y unión de archivos.
- `tests/test_upload_api_extra.py`: agrega pruebas de validación para endpoints de la API.

Comando recomendado:

```bash
python manage.py test upload tests
```
